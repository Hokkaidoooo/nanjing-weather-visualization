# 南京气象数据可视化

收集南京市 2023 年逐日天气，用 matplotlib 绘制月度温度与天气图表，并以南京地图为蒙版制作词云。仓库包含 **365 天数据、5 类图表 × 12 个月及 1 张词云，共 61 张结果图**。

**[浏览 Notebook](WeatherForNanjing.ipynb)** · [查看数据](weather.csv) · [全部结果图](结果图/)

![南京 2023 年天气概览：全年逐日高低温、极值日期与最常见天气类别](assets/readme-weather-overview.png)

基于 `weather.csv` 的全年 365 条记录：左侧为每日最高温与最低温，右侧为最常见的五种完整天气类别。

## 图表分别表示什么

| 图表 | 内容 | 结果入口 |
| --- | --- | --- |
| 折线图 | 每月最高、最低气温的逐日变化 | [12 个月](结果图/折线图/) |
| 散点图 | 每月逐日温度分布 | [12 个月](结果图/散点图/) |
| 饼图 | 每月天气文本类别的组成 | [12 个月](结果图/饼状图/) |
| 热力图 | 日温差的颜色展示 | [12 个月](结果图/热力图/) |
| 3D 图 | 温度数据的三维展示 | [12 个月](结果图/3D立体图/) |
| 词云 | 使用天气文本与地图蒙版生成的历史图形 | [词云](结果图/wordcloud.jpg) |

历史词云将逐日文本连续拼接，可能生成跨日期的组合词，不能直接解释为天气类别的出现频次。热力图日期轴与散点色条的含义也有待完善。

## 数据与复现条件

保存的 `weather.csv` 可按 **GB18030** 解码，日期格式为 `2023/1/1`。数据覆盖 2023 全年，包含 365 个唯一日期、无缺日，最高气温均不低于最低气温。

现有脚本把抓取和绘图连在一起：先请求 12 个月的页面，再覆盖工作目录下的 `weather.csv`。它不是直接读取保存数据的离线绘图入口；日期解析还固定使用 `%Y-%m-%d`，与当前保存 CSV 的格式不同。

如需研究脚本，在独立副本中准备 Python 环境和直接依赖：

```sh
python -m pip install requests lxml numpy matplotlib wordcloud imageio pillow ipython
```

本地交互运行 Notebook 还需要 Jupyter。运行前需核对中文字体路径，并将 `南京地图.jpg` 放在工作目录；字体文件没有随仓库分发。

当前没有经过新环境验证的一条命令复现流程。脚本中的 `savefig` 写入当前目录，不会自动生成现有的 `结果图/` 分类结构；不要直接在保存历史成果的目录执行整段脚本。
